# Nalu

Nalu is a modern e-commerce platform focused on jewelry and fashion accessories.

The project is inspired by open-source e-commerce platforms such as **EverShop**, while being developed independently with its own architecture, design, and implementation.

## Features

* Product catalog and categories
* Product search and filtering
* Shopping cart
* Customer accounts
* Order management
* Inventory management
* Administrative panel
* Authentication and authorization
* Responsive design

## Architecture

Nalu follows a modular architecture focused on **separation of concerns, scalability, security, and maintainability**.

```text
Frontend
   │
   ▼
   API
   │
   ▼
Backend
   │
   ├── Business Logic
   ├── Authentication
   └── Orders
   │
   ▼
Database
```

## Technology

The technology stack is currently under development and may evolve throughout the project.

* Frontend: TypeScript
* Backend: TypeScript
* Database: Relational Database
* Tools: Git, GitHub, Docker

## Project Status

**In development**

Nalu is currently being developed as an e-commerce project and its architecture and features may change as development progresses.
